设计基准：1920 × 1080 CSS 视口 (缩放比：{{ Math.round(currentScale * 100) }}%)
  • 完整度：原页面 8 项搜索字段、14 项表单录入字段无删减。
  • 控件真实性：全量采用 Ant Design Vue 4.0 原生组件（Input, Select, RangePicker, Segmented, Table, Drawer, Modal）。
  • 真实业务数据：注入超过 15 组真实企业大宗交易数据，涵盖 100 字以上地址与备注长文本 Tooltip、空值 `-` 兜底。
  • 操作入口：主次按钮层级分明，录入/新建采用 Primary 蓝底高亮，作废/删除危险操作全部配备 a-popconfirm 二次校验。
  • 批量处理：批量导出与调度操作自动联动行选勾选数量，具备状态防错控制。
  • 消除留白浪费：宽屏采用 4 列等宽网格（Col 6）排布，收起次要低频字段，大幅压缩搜索区域高度。
  • 首屏视野极大化：表格 Y 轴视口自适应锁定，用户在 1920×1080 屏幕下一眼可见至少 12 行以上数据。
  • 无缝迁移至 Vue SFC：自定义样式集中在通用 CSS 类中，未暴力覆盖组件底层样式，前端可秒级迁移。
 本项目代码完全按照 Vue 3 组合式语法 + Ant Design Vue 4.0 规范编写，前端研发直接按以下 3 步即可投产：
  1. 复制 HTML 中的 <div class="page-container">...</div> 粘贴至 <template> 块中。
  2. 复制 <script> 内的 setup() 响应式数据与方法至 <script setup lang="ts">。
  3. 复制 <style> 中的类名样式至 <style scoped>，无任何兼容性冲突。
