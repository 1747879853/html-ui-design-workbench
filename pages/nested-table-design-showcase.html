4 套嵌套表格设计方案决策矩阵

设计方案 视觉核心表现 解决当前系统的痛点 最适用的货代业务场景 改造改动面
风格 1：沉浸卡片内嵌式 (Card Inset) 柔和灰色托盘（#f8fafc）+ 独立白底微圆角投影卡片，父行展开激活时带蓝色边条高亮。 彻底解决原来“内表和外表挤在纯白背景里、像网页破损排版混乱”的丑感，空间层次极强。 付款申请费用明细、发票申请、出海提单装箱明细。 纯 CSS 调优（推荐首选，改动最小效果最棒）。
风格 2：层级导引树线式 (Tree Connector) 展开按钮下方延伸出工程虚线折线导引（L-Guide），子表半开放网格阶梯缩进。 父子归属逻辑极度清晰，取消多余外边框，大幅节省横向与纵向像素空间。 大批量单据审核、海运整箱/拼箱分票明细、BOM 关务申报。 CSS 伪元素结构增加。
风格 3：财务分栏对照式 (Split Summary) 展开后左侧固定宽度的 KPI 指标看板（核销汇总、折算汇差）+ 右侧自适应细项列表。 解决财务对账时“看展开细项就看不到核销单整体汇总指标”的频繁上下滚动痛点。 银行流水核销明细、费用对账确认单、收退款冲抵。 容器增加 2 栏 Grid 布局插槽。
风格 4：极简无界微渐变 (Sleek Borderless) 去除所有硬线边框与厚重色块，用微弱的上下分割线和胶囊徽标统计条区隔。 界面极其呼吸清爽、现代感最强，去掉 90 年代老旧 ERP 的繁琐线条感。 看板级只读明细展示、移动端/平板端自适应、客户账单预览。 纯 CSS 扁平化重写。
