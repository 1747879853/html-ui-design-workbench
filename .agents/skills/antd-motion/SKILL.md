# Ant Design 动效设计

用于具体的 antd 页面或组件动效工作。动效应帮助用户感知状态变化、层级关系或操作结果；没有明确作用的动画应省略。

## 本项目适配

`intelligent-hopper` 使用 Vue 3 + Ant Design Vue 4.x 的独立 HTML 页面。先检查项目内置组件和本地资源；Ant Design React 文档中的主题 Token 只提供设计参照，不能假定其 `ConfigProvider` API 在 Ant Design Vue 中相同。沿用现有 `enterprise-ui-optimization` Skill 的业务字段与布局要求，不为动效自动引入额外框架或远程依赖。

## 工作方式

1. 先列出交互状态和变化：触发者、变化对象、前后位置、反馈目标。检查现有 Ant Design Vue 组件是否已有合适动效，以及项目实际使用的版本、主题和 CSS 变量。
2. 给每段动效写明目的：反馈、引导注意、解释空间/层级或维持视觉连续性。只保留服务于这些目的的变化。
3. 让方向、起点和终点与界面结构一致；进入内容可被感知，退出应更简短，不用冗长的依次离场。时间与缓动按元素大小、距离和任务紧迫度选取；优先读取当前主题的动效 Token。
4. 实现时优先沿用 antd 组件及项目现有动画方案。自定义效果优先使用适合的 `transform` / `opacity`，避免大量同时驱动布局和重绘；不要因为旧文档示例而直接加入旧动画库。
5. 检查 `prefers-reduced-motion` 下是否能减少非必要运动，且状态、结果仍清楚；在真实浏览器验证连续点击、打开/关闭、数据加载、列表增删、低性能场景中的流畅性。

按需读取 [动效参数与场景参考](references/decisions.md)，其中区分 Ant Motion 旧版设计语言示例与当前 antd Token。若任务主要涉及页面结构或操作路径，同时使用 `$antd-in-place-ux`。

交付时简要说明每段动效的作用、采用的时长/缓动来源，以及如何处理减少动态效果和性能。
